# deepwater-digital/.github

Read README.md and ARCHITECTURE.md first. DWD's rules live in `../dwd-kb` (CONVENTIONS.md, DECISIONS.md); they win over anything here.

- This repo is public. Never put secrets, client names or internal details in it.
- Changes go through a PR. A change to `ci.yml` affects every repo that bumps its pin, so test it on this repo's own PR first.
- Actions are GitHub's own or verified, pinned to a full commit SHA. Downloads are checked against a pinned hash.
- No em or en dashes. Plain language, short sentences.
